## 🔗 JSON Endpoint

`https://ds6.github.io/quotes/anime.json`

## 📝 JSON Structure

| Field       | Type    | Description                |
| ----------- | ------- | -------------------------- |
| `character` | String  | Name of the character      |
| `quotes`    | String  | The quote text             |
| `anime`     | String  | Title of the anime         |
| `episodes`  | Integer | Episode number             |
| `category`  | Array   | List of tags or categories |
